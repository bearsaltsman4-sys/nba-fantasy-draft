# NBA All-Time Fantasy Draft

## Overview
A free, browser-based NBA fantasy draft application where players can create lobbies and draft legendary NBA players to build their all-time dream teams.

## Features

### Current Features
- **Create Lobbies**: Generate unique 6-digit lobby codes
- **Join Lobbies**: Connect with other players using lobby codes
- **All-Time Player Pool**: 50+ legendary NBA players from different eras
- **Live Draft**: Real-time draft interface with player searches
- **Draft Log**: Track all picks with player names, positions, and round info
- **Team Display**: View your selected players organized by position
- **Search Functionality**: Filter players by name or position

### Game Rules
- Each team drafts 15 players per round
- Turns rotate through all participants
- Each player can only be drafted once
- Search and select players from the database

## Getting Started

### Local Setup
1. Clone the repository
2. Open `index.html` in a modern web browser
3. Enter your name and create or join a lobby

### Creating a Lobby
1. Enter your player name
2. Click "Create Lobby"
3. Share the 6-digit code with other players

### Joining a Lobby
1. Enter your player name
2. Click "Join Lobby"
3. Enter the 6-digit lobby code
4. Click "Confirm Join"

## How to Play

1. **Search for Players**: Use the search bar to find NBA players
2. **Select Players**: Click on a player to add them to your team
3. **Wait Your Turn**: Turns rotate through all players in the draft order
4. **Build Your Team**: Draft 15 players to complete your all-time dream team
5. **View Draft Log**: See all picks made in the lobby
